# Reels library

Every reel the pipeline finishes is copied here automatically (full 1080x1920 quality) with a `.json` file next to it:
topic, subject, class, job id, look and layout, QA notes and the narration.

**These are test renders made while building the tools.** They are not reviewed, not published and not final content.
Videos are not committed to git (see `.gitignore`); the metadata files are small and can be.
The folder is set in `config/pipeline.json` (`archive_dir`).

Browse them with the tracker: `docs/tracker/index.html`.
