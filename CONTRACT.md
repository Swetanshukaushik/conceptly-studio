## 2. Universal Curriculum Taxonomy & Namespacing

To support diverse professional domains—from **NCERT School** to **UPSC, Medical NEET, Product Management, Finance, and Tech**—without schema divergence, all curricula follow a **Universal 4-Level Knowledge Graph (L0 $\longrightarrow$ L3)**.

```
[ L0: Domain / Track ]       (e.g., school, upsc, medical, pm, finance, tech)
       │
[ L1: Category / Stream ]    (e.g., class-9-science, gs2-polity, cardiology, product-metrics, valuation)
       │
[ L2: Module / Theme ]       (e.g., force-and-motion, fundamental-rights, arrhythmology, retention, dcf)
       │
[ L3: Micro-Concept / Topic ] (e.g., newton-third-law, article-21, action-potential-0, power-user-curve, wacc)
```

### Deterministic Namespaced Slugs (Universal Primary Key)

All topic IDs across the system follow the immutable namespaced format:
$$\mathbf{ID = \{\text{domain}\}:\{\text{category}\}:\{\text{module}\}:\{\text{concept}\}}$$

#### Domain Examples:

## 4. AI Scriptwriter Agent Personas by Domain

When generating reels, the Studio Scriptwriter Agent must adopt the designated pedagogical tone:

* **UPSC:** Senior Civil Services Faculty. Tone is authoritative, constitutional, structured, highlighting Supreme Court precedents and analytical keywords essential for Mains answers.
* **Medical / NEET:** Clinical Academic Consultant. Tone is precise, pathophysiology-driven, diagnosing visual symptoms and emphasizing high-yield clinical pearls.
* **Product Management:** FAANG Principal PM. Tone is pragmatic, strategic, emphasizing user psychology, metrics tradeoffs, and product execution.
* **Finance:** Wall Street Investment Banking Mentor. Tone is crisp, quantitative, tracing balance sheet mechanics, cash flow velocity, and valuation drivers.
* **School (NCERT):** World-class Interactive Science/Math Communicator (like 3Blue1Brown or Veritasium). Tone is engaging, visual, counter-intuitive, and curiosity-sparking.

## 5. Media & Video Specifications

| Property | Requirement | Notes |
| :--- | :--- | :--- |
| **Aspect Ratio** | `9:16` (Vertical) | Single universal master format for mobile and desktop |
| **Resolution** | `1080 × 1920` px (FHD) | Razor-sharp text, code, and diagram rendering |
| **Container & Codec** | `.mp4` (`H.264`, `AAC`) | Maximum hardware decoding compatibility |
| **Fast-Start Flag** | `-movflags +faststart` | **Mandatory:** Moves `moov atom` to start for instant streaming |
| **Target Bitrate** | `CRF = 23` | File size sweet spot: **$8\text{ MB} - 12\text{ MB}$** for 45 seconds |
| **Frame Rate** | `30 fps` | Smooth animation and subtitle timing |
| **Duration** | `35 – 55 seconds` | Target sweet spot: **45 seconds** |
| **Audio Mixing** | Voice: `-14 LUFS` / BGM: `-22 dB` | Voice must always be crystal-clear and prominent |
| **Poster Image** | `poster.jpg` ($\sim 40\text{ KB}$) | Displayed instantly while video stream buffers |

### ⚠️ UI Safe Zones (Screen Overlay Protection)
* **Top 120px:** Reserved for back button and reel count progress (`1/5`). Do **not** place critical text or charts here.
* **Bottom 320px:** Reserved for title, subject chips, Quiz button, and Bookmark icon.
* **Safe Content Zone:** Center vertical range between `Y = 180px` and `Y = 1580px`. Subtitles anchored around `Y = 1350px` – `1450px`.

## 6. Storyboard Pacing Contract (The 4-Act Formula)

Every educational reel must strictly follow this second-by-second pacing curve:

```
[00s - 04s]  ACT 1: The Hook (Counter-intuitive paradox or high-stakes question)
[04s - 25s]  ACT 2: The Core Intuition (Analogy + animated diagram/chart)
[25s - 42s]  ACT 3: The Real-World Application (How cases, drugs, rockets, or systems work)
[42s - 48s]  ACT 4: The 1-Second Takeaway + Call to Checkpoint Quiz
```
