# Conceptly Studio $\longleftrightarrow$ Conceptly Core Integration Contract

**Version:** 1.0.0  
**Target Backend API:** `https://conceptly-api.onrender.com/v1`  
**Target Web/Mobile Client:** `https://conceptly-web.onrender.com`

---

## 1. Why This Contract Exists
This document serves as the single source of truth for **Conceptly Studio**. Any reel, animation, subtitle, or quiz question generated by the Studio agents must strictly conform to the schemas, video formats, and UI safe zones defined below to render flawlessly on both mobile and web.

---

## 2. Media & Video Specifications

| Property | Requirement | Notes |
| :--- | :--- | :--- |
| **Aspect Ratio** | `9:16` (Vertical) | Mobile full-screen vertical swipe format |
| **Resolution** | `1080 × 1920` px | Native FHD |
| **Container & Codec** | `.mp4` (Video: `H.264`, Audio: `AAC`) | Universal playback across iOS, Android, and Web |
| **Frame Rate** | `30 fps` | Smooth animation and subtitle timing |
| **Duration** | `35 – 60 seconds` | Target sweet spot: **45 seconds** |
| **Audio Mixing** | Voice: `-14 LUFS` / Background BGM: `-22 dB` | Voice must always be loud, punchy, and prominent |
| **Subtitles** | Burned-in Kinetic / Bouncing | Active word highlighted (Amber/Cobalt) |

### ⚠️ UI Safe Zones (Critical for Screen Overlays)
The Conceptly mobile & web players render native overlays on top of the video:
* **Top 120px:** Reserved for back button and reel count progress (`1/5`). Do **not** place critical text here.
* **Bottom 320px:** Reserved for title, subject chips, Quiz button, and Bookmark icon.
* **Safe Content Zone:** Center vertical range between `Y = 180px` and `Y = 1580px`. Subtitles must be anchored around `Y = 1350px` – `1450px`.

$$\text{ExamType} \longrightarrow \text{ClassLevel} \longrightarrow \text{Subject} \longrightarrow \text{Chapter} \longrightarrow \text{Topic}$$

## 4. API Ingestion Payloads

### A. Publishing a Generated Reel
When a reel video is rendered and uploaded to cloud storage, the Studio calls:
`POST https://conceptly-api.onrender.com/v1/curriculum/reels`

#### Request Body Schema (JSON):
```json
{
  "title": "Newton's Third Law: The Rocket Principle",
  "topicId": "topic-uuid-here",
  "videoUrl": "https://media.conceptly.app/reels/physics-class9-newton3.mp4",
  "durationSec": 48,
  "keyTakeaway": "Forces always occur in matched pairs: action and equal opposite reaction.",
  "summaryNotes": [
    "A force cannot exist in isolation; it requires two interacting objects.",
    "Rockets accelerate not by pushing against air, but by expelling mass backwards.",
    "Action and reaction act on DIFFERENT bodies, so they never cancel each other out."
  ],
  "interviewPitch": "Explain why you don't float away when taking a step on Earth vs space."
}
```

### B. Publishing Associated Quiz Checkpoint Questions
Each reel must be accompanied by 2–3 interactive concept-check questions:
`POST https://conceptly-api.onrender.com/v1/quizzes`

#### Request Body Schema (JSON):
```json
{
  "topicId": "topic-uuid-here",
  "topicTitle": "Newton's Third Law",
  "questions": [
    {
      "id": "q1",
      "text": "If action and reaction forces are always equal and opposite, why do objects accelerate instead of canceling each other out?",
      "options": [
        { "id": "a", "text": "They act on two completely different objects" },
        { "id": "b", "text": "Reaction force occurs after a slight time delay" },
        { "id": "c", "text": "Action force is always slightly greater than reaction" },
        { "id": "d", "text": "Friction eliminates the reaction force" }
      ],
      "correctOptionId": "a",
      "explanation": "Newton's third law pairs act on different bodies (e.g., foot pushes Earth, Earth pushes foot), so they never cancel on a single object."
    }
  ]
}
```

## 5. Storyboard Pacing Contract (The 4-Act Formula)

Every educational reel must strictly follow this second-by-second pacing curve:

```
[00s - 04s]  ACT 1: The Hook (Counter-intuitive question or visual paradox)
[04s - 25s]  ACT 2: The Core Intuition (Analogy + animated diagram)
[25s - 42s]  ACT 3: The Real-World Application (How rockets, biology, or circuits use this)
[42s - 48s]  ACT 4: The 1-Second Takeaway + Call to Checkpoint Quiz
```
