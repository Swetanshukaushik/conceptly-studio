Biology reels are tours of structures and processes.
- Show the structure first as a simple stylised model built from primitives (or `helix` for DNA), then show what flows through it: use `flow` objects (with `pipe` for vessels) along the path, pinned labels on the parts, and a `camera.tour` that follows the flow, colour-coded consistently (for example red for oxygenated blood, blue for deoxygenated).
- Tag the parts in the order the narrator names them and dim or hide the rest so the viewer looks where the voice points.
- Show cycles as a repeating loop with the camera following the flow. Never claim anatomical precision the stylised model does not have; keep labels to what the narration states.
- Use `image` objects only for a real photograph or diagram that the narration names precisely.
