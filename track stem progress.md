# STEM path: progress tracker

Goal: a Free-tier STEM reel (physics first) that matches the quality of the reference "Pulleys Made Super Simple" short:
fixed headline block on top, a 3D render window in the middle, bold caption below, correct physics, force labels.
Everything runs in-house on open-source parts (three.js, KaTeX, headless Chrome, ffmpeg); no paid video models.

Last updated: 2026-10-26 (pulley milestone)

## Decisions
- Build in-house: director/planner, narration-synced editing, captions, QA, caching, spend limits, quiz tie-in.
- Buy / open source: everything else. STEM renders stay in our three.js engine (physics must be deterministic).
- Mechanisms come from a vetted prefab library (config/props/), configured by the LLM; primitives are the fallback.
- Layouts, looks, props, poses, pacing are config files under `config/`; no topic or persona logic in code.
- Real LLM calls (Gemini) are made only after asking the user.

## Acceptance (per topic)
1. `lint` passes (no bad expressions, no black / blown-out frames).
2. Vision QA scores each beat above threshold (to build).
3. User compares frames with the reference short and approves.
